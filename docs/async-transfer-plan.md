# 单文件异步并发传输实施与验收计划

1. 保存当前 Paramiko 实现供同条件基线测试，检查 PMUD2 参考代码的数据完整性缺陷。
2. 以独立 AsyncSSH 传输服务替换上传/下载路径，SSH 命令会话继续由现有 facade/host 管理；单文件使用有界并发和显式 offset。
3. 写入独占临时文件，完整等待所有请求、检查大小与 SHA-256 后才发布最终文件。失败不得覆盖已有目标；短读必须补齐，失败任务必须取消并收敛。
4. 校验优先使用远端 SHA-256 工具；工具不可用时完整回读，在客户端计算 SHA-256。大小一致只作为必要条件，不作为完整性证明。
5. 本地故障服务器重现乱序/短读/同长度损坏/写入失败，检查错误传播、临时文件清理与旧目标保留。
6. 独立手动启动后台服务，另开客户端进程驱动真实 MCP stdio 请求。在 NAS、ABYSS 上分别比较旧版与新版大文件上传/下载，独立验证文件哈希，补测回读校验、空文件与覆盖。
7. 报告分别列出传输时间、校验时间和端到端时间；如性能不提升，如实说明瓶颈与适用边界。

测试只使用本次创建的远端临时目录；凭据从用户环境变量读取，不写入报告。测试实例使用独立端口与状态目录，不重启现有 MCP 实例。
